# Remaining Duration is what the owner says is left, not the estimate minus time worked

dynacal used to work out a Task's Remaining Duration by subtracting the time of its past Blocks from the estimate: an unanswered Block counted as worked, and a "Partly" review counted the minutes the owner typed in. That showed "0m left" on Tasks the owner hadn't finished, and the review asked about a Block while finishing happened on the Task, so "Done" looked like finishing when it wasn't. Now the Check-in asks about the Task ("Finished?"), and Remaining Duration is the estimate until the owner answers More time with how much more it needs; time worked is never counted or asked for. We chose this because the owner knows how much is left better than any arithmetic on time spent (20 minutes in, a Task may need 40 more or 2 hours), and because it lets the owner think only about Tasks. Don't bring back worked-minutes accounting to make Remaining Duration "automatic": that is the confusion this replaced.
